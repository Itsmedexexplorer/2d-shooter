# Retro Web Hunter

Welcome to the **Retro Web Hunter** project! This is a complete Node/React port of the original 2D browser shooter game. It retains all the intentional quirks and bugs from the original version to preserve its unique charm and difficulty.

## 👾 About The Game
Retro Web Hunter is a challenging arcade shooter where you must aim carefully to take down acrobat enemies and drones before they escape. Can you clear all waves with your limited ammo?

**Note:** This game intentionally includes a few "bugs" as gameplay features (such as phantom hitboxes and unexpected enemy behaviors) to make the challenge more frustrating and fun!

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

You will need **Node.js** installed on your system. 
- Download and install Node.js from [nodejs.org](https://nodejs.org/).

### Installation

1. **Clone the repository**
   Open your terminal or command prompt and run the following command to download the project:
   ```bash
   git clone https://github.com/Itsmedexexplorer/2d-shooter.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd 2d-shooter
   ```

3. **Install the dependencies**
   Use npm to install all required packages:
   ```bash
   npm install
   ```

### Running the Game

After installing the dependencies, you can start the local development server by running:

```bash
npm run dev
```

Your terminal will display a local URL (usually `http://localhost:5173`). Open that URL in your web browser to start playing!

## 🎮 Controls
- **Aim:** Mouse or Touch (on mobile)
- **Shoot:** Left Click or Spacebar
- **Difficulty Selection:** Press `1` (Easy), `2` (Medium), or `3` (Hard)
- **Restart:** Press `R`
- **Menu:** Press `Esc`

## 🛠 Built With
- **React** (v18)
- **Vite** (Build tool)
- **HTML5 Canvas** (Rendering)
- **Web Audio API** (Sound effects)
